三、Layer 2 · 必问信息（AskUserQuestion，先问再干，不猜）

③ zovii 项目

④ 模型

四、Layer 3 · 主工作流六步

1

读取表格 · 识别列结构

  • wiki 链接先解析成 sheet token（走 lark-wiki）
  • +workbook-info 拿子表 → +csv-get 读表头与样例
  • 识别列：标题正文 / 图片数量 N / 拆解提示词 / 参考图列（列名含「参考图」，可能多列）
  • 铁律：表头含义读出来逐列与用户核对，不按直觉猜
2

自动加列

  • 按目标行最大图数 MAXN 追加：图1~N提示词、图1~N图片、状态（默认写「待处理」），运行期再自动补「耗时(秒)」
  • 推荐脚本 add_columns.py：自动算列字母、避免维度错误，输出列映射
3

准备参考图 —— 先下载到本地 tmp/，再上传给 zovii NEW

目标目录：<cwd>/tmp/zovii-refs/<任务ID>/refs/<行号>/（任务ID = 时间戳+进程号，多次运行互不干扰）。--image-input 只吃本地路径，所以必须先落地。

单元格形态处理方式
URL 文本curl -L -o 直接下载
单元格图片（embed-image）取 image_token → medias/download；--output 只接受相对路径（先 cd 进目标目录），文件名不可预测必须显式指定
浮动图片+float-image-list 取 token 后下载
云盘/文档链接走 lark-drive skill 下载
  • 命名规范：<行号>-<参考图列名>-<序号>.jpg（如 3-参考图1-1.jpg），下载后维护「行号 → 路径」映射
  • 是否使用参考图以拆解提示词/正文的明示为准，没明示就不下载不使用
4

生成每张图的提示词并回填（核心智能环节）

分工：图 1 = 封面（吸睛主视觉、强对比、大字号标题、情绪钩子）；图 2~N = 配图（按拆解节奏展开场景 / 卖点细节 / 对比 / 步骤 / 证言 / 前后效果）。

每条提示词五段式：① 主体与场景 → ② 画面内容（构图景别动作）→ ③ 风格氛围（光影色调质感）→ ④ 画面文字（具体字句与排版位置）→ ⑤ 参考图声明（仅限明示）→ 统一追加上画质后缀。

回填后该行状态置「提示词已生成」；先给用户看几条样例确认风格，不满意调整后再批量——这是唯一的人工把关点。

5

zovii 生图 · 行间并发 × 行内两段式

行间：多行并发（默认 10 行）

run_rows.py 统一调度：main 串行预取所有输入防飞书限流 → 参考图串行下载进 tmp/ → worker 并发生成回填 → 限流自动退避重试

行内：默认 sequential 两段式（唯一核心概念）

默认 sequential：封面先行、封面 assetId 作所有配图的风格锚点，整组风格一致无需任何提示词表述；仅拆图提示词明确写「每张图独立 / 各图互不相关」才退化为无锚点的 parallel 全图并发。每张参考图用在哪张图，必须在拆图提示词显式声明（如「参考图2用于图片3」）——全显式、无默认分配，未声明不附加、不猜测

  • 只允许 generate-image 单图生成，禁止 batch-generate-image
  • 单张失败自动重试，失败项带 error 记录、不中断后续，整批结束统一汇报（退出码 2）
  • 脚本不可用时手动兜底：generate-image <project> --prompt --image-input ... --model --aspect-ratio --size 2K
6

下载回填 + 收尾清理 NEW·清理

  • fillback_images.py 下载资产并回填单元格图片；脚本内部自动 cd —— 回填路径铁律：--image 只接受当前目录相对路径，绝对路径必被拒
  • 全部成功 → 状态「已完成」；有失败 → 「图片已生成」并在状态备注原因
  • 所有行结束后删除整个参考图临时目录：rm -rf tmp/zovii-refs/<任务ID>（脚本内置 finally 兜底，成败都删；--keep-tmp 可调试保留）

五、行状态机（中断可续跑）

状态列贯穿全程；续跑时按状态跳过已完成行。

待处理─ 提示词回填完 ─▶ 提示词已生成─ 图片全部回填 ─▶ 已完成 └─ 存在失败图 ─▶图片已生成（备注失败原因，修复后续跑）

六、文件去向一览

📄 飞书表格最终交付

图1~N提示词列、图1~N单元格图片、状态、耗时(秒) —— 一切成果沉淀在表格里

🗑️ tmp/zovii-refs/<任务ID>/NEW

参考图临时区：任务开始下载进来，任务结束 finally 自动删除；超 3 天残留目录启动时清扫；--keep-tmp 仅调试用

🖼️ xiaohongshu/<日期>/images/

生成图本地副本（交付物留存），同时是回填飞书的工作目录（相对路径要求）

七、决策铁律速览

  1. 先问再干：颗粒度、模型、比例三问必须在开工前完成
  2. 只单图生成：一律 generate-image，禁 batch
  3. 默认 sequential，封面必为配图锚点：显式声明整组独立才回退无锚点并发
  4. 行间并发 10 行，参考图按行隔离在 tmp/ 子目录
  5. 列名不猜：读出来核对一次
  6. 状态可追踪：中断续跑按状态跳过已完成行
  7. 失败不静默：记录原因，最后统一汇报清单
  8. 回填相对路径：cd 进图片目录再用 ./xxx.png
  9. 参考图全显式，无类别：参考图列=列名含「参考图」；每张参考图用在哪张图由拆图提示词显式声明，未声明不参与生成（stderr 提醒），无任何默认分配
  10. 参考图临时化 NEW：先落 tmp/ 再上传，任务结束必删；生成图是交付物不在此列
